# Why Adult Game Manager?

AGM provides one local library and update view across Android APKs and several
extracted-game workflows without turning launcher libraries into its source of
truth.

| Workflow | Separate manual tools | With AGM |
| --- | --- | --- |
| Find installed games | Check Android and each launcher separately | Search one local library |
| Check known versions | Revisit individual source pages | Compare matched games with public catalog metadata |
| Launch games | Remember which runtime owns each game | Start compatible games from the AGM entry |
| Replace local archives | Manually decide what each file changes | Review a planned multi-file install/upgrade operation |
| Work with saves | Locate engine-specific paths manually | Use supported Ren'Py/RPG Maker discovery and backup-aware tools |
| Privacy | Depends on every tool used | AGM itself is local-first, has no analytics, and requires no site login |

AGM is not a game store or automatic downloader. Catalog metadata can lag a
live source page, and runtime compatibility still belongs to the selected
launcher.
