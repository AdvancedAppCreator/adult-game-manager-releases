# Save-file safety

Treat a working save as irreplaceable even when a game archive can be
downloaded again.

## Before an upgrade or edit

1. Close the game and its launcher.
2. Use AGM's supported save discovery or backup action.
3. Keep one copy outside the game installation folder.
4. Confirm the backup has files and a recent timestamp.
5. Only then replace game files or edit a save.

AGM's supported Ren'Py and RPG Maker save tools create backups before edits,
but a separate copy remains useful when a game uses a custom save location.

## After an upgrade

1. Launch the game without deleting the previous installation immediately.
2. Load a known save.
3. Create a new save in a different slot.
4. Confirm both can be loaded after restarting the game.
5. Remove old files only after the replacement and saves are proven.

Android versions, launchers, and individual games can use different storage
locations. Never assume that an installation-folder backup includes every
save.
